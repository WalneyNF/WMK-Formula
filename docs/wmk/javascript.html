Monaco e JavaScript — API real

O Code Studio disponibiliza uma API cliente pequena. O editor web usa o servidor Python local para controlar o processo Rust; Monaco é o editor, não o motor de cálculo.

Exemplo de leitura e escrita

const origem = await wmk.sheet.getCell("A1");
const dobro = Number(origem.value) * 2;
await wmk.sheet.setCell("B1", dobro);
console.log("B1:", dobro);

Operações expostas pelo cliente existente

JavaScriptComando da Bridge
wmk.sheet.getCell("A1")cell.get
wmk.sheet.setCell("A1", "250")cell.set
wmk.sheet.getRange("A1:C10")sheet.read

API HTTP direta

GET /api/v1/health
POST /api/v1/command
Content-Type: application/json
X-WMK-Token: (token efêmero injetado no navegador)

{"method":"cell.get","params":{"cell":"A1"}}

O servidor exige token e verifica a origem das chamadas. Não copie tokens em repositórios, não disponibilize a porta local na internet e não execute scripts desconhecidos. A implementação de scripts está em estágio experimental e não oferece sandbox de confiança para código hostil.
