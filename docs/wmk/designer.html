Form Designer — controles e propriedades

No modo Designer, os controles podem ser selecionados, movidos e redimensionados. A árvore mostra a estrutura do formulário e o painel de propriedades modifica o controle selecionado.

Passo a passo

  1. Abra /designer.html e clique em Novo.
  2. Insira Label, TextBox, Button, ComboBox, CheckBox ou DataGrid pela Widget Box.
  3. Selecione um controle, ajuste nome, posição, largura, altura e aparência.
  4. Use Salvar JSON para exportar o projeto e Abrir JSON para importá-lo.
  5. Pressione F5 para alternar entre editar e executar.

Tipos presentes nesta versão

ControleUso
LabelTítulo ou legenda
TextBox / TextAreaCampos editáveis
CheckBoxValor booleano TRUE/FALSE
ComboBoxEscolha uma das opções cadastradas
ButtonDisparo de ações demonstrativas
DataGridExibição dos registros da faixa
PanelOrganização visual inicial

A criação de controles por plugins, herança visual universal e layouts automáticos ainda são propostas para o SDK; não estão prontas na v0.5.2.

Regra importante

O projeto JSON descreve controles e propriedades. Ele não é um arquivo de banco de dados e não substitui backup da planilha.
