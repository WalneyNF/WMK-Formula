Primeiro contato — da planilha ao formulário

O WMK Web Designer é um editor web independente conectado ao WMK Formula (motor Rust) por uma Bridge Python. Permite desenhar formulários e alimentar células reais sem VBA.

O que funciona na v0.5.2

RecursoEstado
Bridge local e controle de célulasTestado no Windows com a planilha Rust
Editor Monaco e execução JS isoladaTestado no Windows; Monaco pode depender de CDN
Designer visual e DataGrid de planilhaTestado no Windows
CheckBox/ComboBox e CRUD de 40 linhasTestado no Windows
Plugins de terceiros, MCP, IA, SQL e tabelas dinâmicasPlanejados; ainda não implementados

Instalação simples

  1. Copie o conteúdo desta distribuição para D:\Ferramentas\WMK-Bridge.
  2. Confirme que o WMK Formula foi previamente compilado e está disponível em D:\Ferramentas\gridcraft\target\debug\WMK-Formula.exe.
  3. Dê dois cliques em INICIAR-WMK.cmd.
  4. O inicializador tentará abrir o motor (porta 7979), iniciar a Bridge e abrir o navegador na porta 8773.

Não execute vários servidores da mesma versão na mesma porta. Use uma planilha de teste antes de operar em documentos importantes.

Onde ficam as ferramentas?

http://127.0.0.1:8773/ → Code Studio. http://127.0.0.1:8773/designer.html → Form Designer. Consulte o indicador de versão no cabeçalho.
