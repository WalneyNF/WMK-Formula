CRUD na planilha — exemplos e limites

O cadastro experimental mapeia campos de entrada para colunas consecutivas da planilha real. Leia os limites antes de usar.

Exemplo prático

ColunaControleExemplo
AtxtNomeMaria
BtxtCidadeNova Friburgo
CCheckBoxTRUE
DComboBoxOpção B
  1. Crie os campos e alterne para Executar.
  2. Preencha e use Adicionar linha.
  3. Inclua mais dois cadastros e observe as novas linhas na planilha.
  4. Selecione uma linha na DataGrid; confira que os campos foram restaurados.
  5. Use Salvar edição ou Remover linha após confirmar a seleção.
  6. Use Localizar para procurar registros carregados.

Limitações técnicas

O CRUD v0.5.2 trabalha com janela de 40 linhas e até 12 campos de entrada, mapeados pela ordem. Não usa chave primária estável, transações ACID ou banco SQL; a Bridge grava células individualmente. A remoção compacta células das colunas controladas, não apaga uma linha estrutural inteira.

Não use esse CRUD diretamente sobre uma planilha empresarial importante. Salve cópia de segurança e teste com dados fictícios.
