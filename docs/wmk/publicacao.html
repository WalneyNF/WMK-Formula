Publicação no GitHub — passo a passo

Este material foi preparado para publicação, mas não foi enviado automaticamente ao GitHub.

Fluxo sem linha de comando

  1. Crie um novo repositório público com nome WMK-Web-Designer.
  2. Extraia o pacote ZIP num diretório temporário e confira seu conteúdo.
  3. No GitHub, use Add file → Upload files para enviar os arquivos e pastas, preservando a estrutura.
  4. Revise o preview, clique em Commit changes e confirme que README, LICENSE, NOTICE e manuais aparecem online.
  5. Na seção Releases, publique a tag v0.5.2-docs1 e anexe o ZIP, caso deseje distribuição pronta.

Checklist final

Verificar créditos, licenças, segurança, ausência de credenciais, versões, testes Windows e documentos. Não publique cópias do motor Rust sem revisar marcas, fontes e dependências.

Pacote do motor Rust

O WMK Formula (executável Rust) é um produto separado. Sua distribuição exige atribuição original do GridCraft e auditoria específica. Este ZIP contém apenas ferramentas web e a Bridge Python.
