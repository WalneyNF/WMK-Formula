# Créditos e materiais de terceiros

O pacote não contém código-fonte do motor Rust GridCraft, nem arquivos do Monaco Editor.

- O software Rust GridCraft é projeto anterior do ArtCraft Team e colaboradores; dados de licença e atribuição de referência em `licencas/`.
- Monaco Editor é obtido por URL remota na implementação web atual; verificar obrigações e licenças quando decidir vendorizá-lo/embuti-lo.
- Elementos visuais WMK fornecidos no contexto do projeto foram incluídos em `web/assets/`; confirme a titularidade e permissão de publicação desses arquivos antes de divulgar.

Um inventário definitivo de dependências para distribuição pública do motor exige auditoria separada de Cargo/artefatos de build.
