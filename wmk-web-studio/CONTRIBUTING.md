# Como contribuir

1. Abra uma issue com a proposta ou defeito e descreva como reproduzi-lo.
2. Envie um pull request com testes quando possível.
3. Não introduza material de terceiros sem checar licença e créditos.
4. Informe claramente os arquivos alterados e preserve os avisos aplicáveis.
5. Ao contribuir, confirme que tem direito de enviar o código sob Apache 2.0.

Não é exigida cessão automática de todos os direitos autorais ao mantenedor.
